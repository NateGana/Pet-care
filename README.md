# 🐾 PetCare

A simple pet care and appointment tracker for pet owners. It keeps track of pets, vaccinations, appointments and care reminders.

> This is a personal tracking app, not a medical diagnosis tool.

## Main Features
- Dashboard with totals and an **Upcoming Care** list sorted by date
- Pet profiles: add, edit, delete and search
- Appointments: add, edit, delete, mark completed, search and filter by status
- Vaccination records with next due dates
- Care reminders with pending / completed status
- Date indicators (Today, In 3 days, Overdue)
- Data saved in your browser with LocalStorage
- Responsive design with modal forms and toast messages

## Technologies
HTML5, CSS3, Vanilla JavaScript, LocalStorage

## How to Run
Open `index.html` in any modern browser. No install or server needed.
